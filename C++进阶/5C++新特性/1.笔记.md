decltype 
括号内的表达式只在编译期进行类型分析，不会在运行时被执行。

推导结果即为该标识符声明时的确切类型（保留 const、volatile 和引用修饰符 &）。

左值    推导为左值引用  T&
将亡值  推导为右值引用 T&&
纯右值  推导为普通类型 T


在模板函数中，当返回值依赖于模板参数的运行结果时
用auto （函数）-> decltype
template <typename T, typename U>
auto add(T x, U y) -> decltype(x + y) { // 在函数参数声明后推导类型
    return x + y;
}
