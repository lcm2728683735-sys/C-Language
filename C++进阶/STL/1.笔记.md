STL:standard template library 标准模板库
组件：
容器+迭代器+算法
仿函数 适配器 空间配置器

容器：各种数据结构（vector, list, map 等），用于管理和存储数据。
迭代器：扮演容器与算法之间的粘合剂。通过统一的接口（*, ++, !=）屏蔽底层物理存储差异。
算法（Algorithms）：各种常用常用逻辑（sort, find, copy 等）。算法不直接操作容器，而是通过操作迭代器区间 [begin, end) 实施。
仿函数/函数对象：重载了 operator() 的类或 Lambda 表达式，为算法提供自定义策略（如降序排序规则）。
适配器：用于修饰接口
空间配置器：负责底层内存的动态分配、管理与释放，实现内存管理与对象构造的解耦

迭代器失效
在对容器进行增删改时，必须清楚迭代器的生命周期：

顺序容器：vector 在 push_back 发生 Reallocate（重新分配内存）时，所有迭代器失效；在中间 erase 时，被删位置及之后的迭代器失效。
树形关联容器：map/set 在 erase 时，仅被销毁节点的迭代器失效（可用 m.erase(it++) 或 C++11 返回的新迭代器接手）。
哈希容器：未发生 Rehash 时仅被删节点失效；触发 Rehash 时全部失效。

函数调用方式：仿函数，函数指针，lambda，function

仿函数（函数对象）:重载了函数运算符的类或者结构体
作用：让一个对象可以像普通函数一样被调用，同时具备函数所不具备的状态保持和类型特征能力
使用：函数运算符重载


匿名函数：
[]:捕获对象
():函数参数列表
{}:函数主体
->:返回值

Lambda 本质上是编译器在编译期自动生成的一个匿名仿函数（无名类/结构体）。

捕获原理：
按值捕获：被捕获的变量作为成员变量存储在匿名类中，在构造时进行值拷贝。
按引用捕获：匿名类中存储的是外部变量的指针或引用。
[ 捕获列表 ] ( 参数列表 ) mutable 异常说明 -> 返回类型 { 函数体 }

function:头文件中的通用可调用对象包装器
有了 std::function，只要“输入参数类型”和“返回值类型”匹配，它们就可以被装入同一个 std::function 变量中。(核心机制:`类型擦除`)

| 操作        | 常见函数    | 作用       |
| ------      | ---------- |   -------- |
| 判断是否为空 | `empty()` | 容器有没有元素|
| 获取元素数量 | `size()`  | 当前元素个数  |
| 清空       | `clear()`  | 删除所有元素  |
| 插入       | `insert()` | 插入元素     |
| 删除       | `erase()`  | 删除元素     |
| 查找       | `find()`   | 查找元素     |
| 遍历起点   | `begin()`  | 返回首元素迭代器|
| 遍历终点   | `end()`    | 返回尾后迭代器  |
| 交换       | `swap()`   | 交换两个容器    |
| 获取首元素  | `front()`  | 第一个元素     |
| 获取尾元素  | `back()`   | 最后一个元素   |
