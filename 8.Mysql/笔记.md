# 索引
：数据库中对一列或者多列的值进行排序的一种数据结构

索引是创建了本地文件，存在硬盘中的二叉树(红黑树)

B树:检索索引时减少磁盘io
原理：一个节点存多个数据

B+树：
1、将所有的有效数据都放在叶子里,中间节点只放key
2、叶子之间用指针连接，形成双向链表

优点:1、中间节点可以存放更多key,减少IO
     2、查询的终点都是叶子，查询效率更稳定
     3、更好的支持范围查询

show index from 表名:显示索引 
create index 索引名 on 表名(字段名) :创建索引
drop index 索引名 on 表名 : 删除一个索引

索引的优缺点:
    优点：1.提升了查找效率
         2.IO次数减少
    缺点 1.消耗额外硬盘空间
        2.增删改查时需要维护索引，增加了数据库的操作，拖慢了速度

索引的使用时机:
        1.频繁查找的列
        2.不经常修改的列
        3.主键


# 事务
多个数据库处理指令作为一个整体，要么都成功，要么都不成功

四个特性：
原子性：事务是一个完整操作，要么都执行，要么都不执行
一致性：事务执行的结果符合预期
隔离性：事务与事务之间互不影响
持久性：事务操作成功后修改应该是永久性的

事务在并发中的问题:
1、脏读(读其他事务还没有提交的数据)
2、不可重复读(一个事务读取同一个数据两次结果不一致(另一个事务修改了数据))
3、幻读

事务的隔离级别:
1、提交读:解决脏读
2、可重复读:  解决不可重复读  mysql默认可重读级别
3、串行化:解决幻读问题
