库：代码仓库
库文件：动态库 静态库

静态库：.a
ar:制作静态库
-r:将某个.o文件插入到静态库当中
-c：创建一个新的静态库
-s:重置静态库索引  
ar rsc lib+库名.a 库名.o.
生成.a 静态库文件

静态库的使用：编译期直接编译到程序当中

动态库(共享库 (带-fPIC时共享))：lib+库名.so (.dll)
在编译期不会编译到程序中，而是在运行时链接

-shared制作动态库
-fPIC生成的库代码位置独立 

ldd:查看程序依赖的库
依赖动态库的程序运行时需要带上动态库
sudo cp DynamicArray.h /usr/include
sudo cp libDynamicArray.so /usr/lib
