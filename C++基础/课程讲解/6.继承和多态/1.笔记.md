## 继承：一个类可以获得另一个类的成员，并在此基础上增加自己的功能
    目的：提高代码的复用性

*继承方式*
1、public：  公用继承 pb->pb pt->pt pv->pv
2、protected 保护继承 pb->pt pt->pt pv->pv
3、private   私有继承 pb->pv pt->pv pv->pv 

父类的私有成员可以被继承但是不可见
子类可以调用父类的构造函数对父类的变量进行初始化，这个函数得在初始化列表中调用
子类可以使用父类的protect；
父类的所有成员在子类都不可见
*名词遮蔽*父类与子类用同名函数，只能调用的是子类，除非用域解析

继承中的static
 
开闭原则：对修改关闭，对扩展开放

多继承：同时继承多个类进行整合操作
父类构建顺序和继承关系相关

class a : public b
a继承b
b是父类a是子类

a属于b
用于表示属于关系
继承后子类可以使用父类的public和protect

函数构造：先构造父类后子类
析构：先子类后父类

虚继承指针->虚继承表（虚继承类相对于本类的偏移量

组合：把要用到的对象放在创建的类里

## 多态：同一个接口，表现出不同的行为
构成条件：
1.父类指针指向子类对象
2.要有虚函数
3.子类重写虚函数

静多态：编译期进行函数地址绑定   c:函数指针 c++：函数重载
运行时多态：函数在运行时预计*实际对象类型*决定调用对应函数 虚函数

## virtual虚函数

*实质：父类指针，指向子类对象，通过虚函数调用子类版本*

虚函数可以实现动态绑定

## 纯虚函数
virtual ... = 0  是纯虚函数
纯虚函数只负责定义函数
具体实现交给子类

## *override*：在子类中实现重写父类的虚函数时检查父类没有会报错



## 抽象类

只要一个类拥有纯虚函数，这个类就是抽象类

抽象类可以定义一个统一接口
抽象类不能直接创建对象但是可以使用指针，并创建对象

虚析构函数：virtual ~Animal() = default;


代码解释：
class Animal
{
public:
    virtual void speak() = 0;

    virtual ~Animal() = default;
};

class Dog : public Animal
{
public:
    void speak() override
    {
        cout << "汪汪" << endl;
    }
};

class Cat : public Animal
{
public:
    void speak() override
    {
        cout << "喵喵" << endl;
    }
};

Animal* a = new Dog;
Animal* b = new Cat;

a->speak();
b->speak();

delete a;
delete b;

                    Animal
                      │
              ┌───────┴───────┐
              ↓               ↓
             Dog             Cat
              │               │
          speak()          speak()
              │               │
              └───────┬───────┘
                      ↓
                virtual speak()
                      ↓
                  多态调用

总结：
① 继承：
子类可以继承父类的成员，并扩展自己的功能。

② public 继承：
表示明显的“is-a”关系，例如 Dog is an Animal。

③ virtual：
让通过父类指针/引用调用函数时，可以根据实际对象类型选择函数。

④ override：
明确告诉编译器“我要重写父类虚函数”，让编译器帮你检查。

⑤ 纯虚函数：
virtual void func() = 0;
规定接口但不提供具体实现，使类成为抽象类。

⑥ 多态：
父类指针/引用指向子类对象 + 虚函数 = 运行时多态。
