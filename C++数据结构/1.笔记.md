数据结构：数据的存储方式和处理方式

线性表：除第一个节点外，其余节点有且仅有一个前驱节点
除最后一个节点外，其余节点有且仅有一个后驱节点

顺序表：地址连续（数组）
链表：地址不连续

数组插入：尾插法O(1) 头插法 中间插入O(n)
删除：位置删(O(n))  值删(O(n^2))
查找：位置查(O(1))  值查(O(n))
修改：位置查(O(1))  值查(O(n))

链表： 通过指针寻找下一个元素
一个元素叫做node节点
头节点：不放有效数据，只是辅助操作链表
head指针指向链表的第一个节点
head = nullptr 表示这是空链表

## 遍历指针（核心操作）
Node* current = head;
while(current != nullptr)
{
    std::cout << current->data << " ";

    current = current->next;//把current指针移动到下一个节点
}
