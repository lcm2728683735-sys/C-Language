内存：掉电数据不保存
外存：掉电数据保存

文件：储存在外部介质上的一组相关的有序数据的集合

文本文件   ：字符编码的文件（ascii GBK unicode:UTF-8）
二进制文件 : 基于值编码的文件（jpg mp3 mp4）

#define SEEK_SET	0	/* Seek from beginning of file.  */

#define SEEK_END	2	/* Seek from end of file.  */

第三个参数：
| 参数         | 含义    |
| ---------- | ----- |
| `SEEK_SET` | 从文件开头 |
| `SEEK_CUR` | 从当前位置 |
| `SEEK_END` | 从文件末尾 |

全缓冲：缓冲区满才输出
linux默认缓冲区大小：1024字节

feof(fp)判断文件是否到达EOF
