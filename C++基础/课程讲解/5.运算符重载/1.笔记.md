运算符重载：给已有的运算符赋予全新的功能
operator加上运算符
*本质*：函数调用

输入输出运算符的重载：
1、ostream得传&
2、要全局重载（写法习惯）
3、返回ostream&

传入参数有 const修饰表示传入一个不可修改的对象
传入参数有 &表示以引用的方式接受一个对象
运算符重载+

        MyInt temp;

常见的运算符重载：

a++和++a

*a++：*

MyInt& operator++()
{
    ++value;
    return *this;
}

*++a*

MyInt operator++(int)
{
    MyInt temp = *this;
    value++;
    return temp;
}

区别是一个先增加在返回，另一个是先返回旧值再增加

<<重载

ostream& operator<<(ostream& os,const MyString& str)
{
    os << str.//要输出的值
    return os;
}

>>同理

| 运算符 | 常见形式  |     重点        |
| ----- | --------- | -------------- |
| `+`   | `a+b`     | 返回新对象      |
| `-`   | `a-b`     | 返回新对象      |
| `==`  | `a==b`    | 通常返回 `bool` |
| `!=`  | `a!=b`    | 通常返回 `bool` |
| `=`   | `a=b`     | 通常返回 `T&`   |
| `[]`  | `a[i]`    | 通常返回引用    |
| `++a` | 前置      | 返回 `T&`       |
| `a++` | 后置      | 参数加 `int`    |
| `<<`  | `cout<<a` | 通常非成员      |
| `>>`  | `cin>>a`  | 通常非成员      |
| `()`  | `a()`     | 必须成员        |
| `->`  | `a->x`    | 必须成员        |

*智能指针*:解决动态内存的自动管理问题
常见智能指针
std::unique_ptr->独占
std::shared_ptr->共享
std::weak_ptr->弱引用

std::unique_ptr<int> p = std::make_unique<int>(10);

相当于int* p = new int(10);

但是unique_ptr自动释放

更推荐：
auto p = std::make_unique<int>(10);
