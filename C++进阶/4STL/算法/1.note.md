算法名称,功能说明,关键注意点
std::for_each,对区间内每个元素执行函数/Lambda,可搭配 C++11 Lambda 使用
std::find / std::find_if / std::find_if_not,查找指定值 / 满足条件 / 不满足条件的第一个元素,返回对应位置的迭代器，未找到返回 end()
std::count / std::count_if,统计指定值 / 满足条件的元素个数,返回数值类型 difference_type
std::all_of / std::any_of / std::none_of,检查是否所有 / 至少一个 / 没有任何元素满足条件,C++11 引入，返回 bool
std::adjacent_find,查找一对相邻且相等的元素,可传自定义二元谓词
std::search / std::find_end,在主序列中查找子序列首次 / 最后一次出现的位置,-
