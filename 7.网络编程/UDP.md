udp接收：(服务端)
1、*创建 Socket*：
使用 socket() 函数创建一个 UDP 套接字

2、*绑定地址*（Bind）： 
使用 bind() 函数将套接字绑定到一个本地的 IP 地址和端口上，以便客户端能找到它。

3、*接收/发送数据*： 
使用 recvfrom() 接收客户端发来的数据，并可以通过 sendto() 将响应发回给客户端。
‘
4、*关闭 Socket*： 
使用 close() 关闭套接字。

UDP发送：（客户端）
1、*创建 Socket*： 
使用 socket() 创建套接字。

2、*发送数据*： 
直接使用 sendto() 向服务器的 IP 和端口发送数据（系统会自动为客户端分配一个临时端口）。

3、*接收数据*（可选）： 
使用 recvfrom() 接收来自服务器的回复。

4、*关闭 Socket*： 
使用 close() 关闭套接字。
